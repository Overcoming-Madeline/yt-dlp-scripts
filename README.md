# yt-dlp-scripts
A small collection of yt-dlp scripts that are made to make downloading videos/audio a bit easier.

## How To Install

**Firstly git clone the repo**

``` bash
git clone https://github.com/Overcoming-Madeline/yt-dlp-scripts.git
```

**And cd into the repo**

``` bash
cd yt-dlp-scripts
```
 
 **Then add directory to $PATH**

``` bash
echo "export PATH="INSTALL DIRECTORY:$PATH"" >> ~/.bashrc
```
### Or if you using zsh
``` bash
echo "export PATH="INSTALL DIRECTORY:$PATH"" >> ~/.zshrc
```

### Chmod +x all the scripts

``` bash
chmod +x yt-*
```
